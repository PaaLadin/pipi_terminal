# SOVINTEL TERMINAL SYSTEM MANIFEST — PRODUCTION RELEASE v1.0
*Hardware Platform: Raspberry Pi | Display Unit: em713 (1024x600 via Pygame Framebuffer)*

## 1. АРХИТЕКТУРА И ФУНКЦИОНАЛЬНЫЕ МОДУЛИ ЭКРАНОВ
Система разделена на 6 независимых функциональных экранов (вкладок `MODULES`), отрисовываемых каскадно в главном цикле `terminal.py` с частотой 30 FPS:
* `matrix_screen` (Tab 0) — Экран-заставка «Каскадный обвал кода». Отключает отрисовку координатной сетки и верхних OSD-вкладок.
* `dash_screen` (Tab 1) — Основной рабочий Dashboard. Отображает текущий статус воспроизведения аудио, информацию о выбранной радиостанции, актуальные погодные информеры, бегущую строку новостей (`news_scroll_x`), а также блок мониторинга раздачи бесплатных игр со 100% скидкой и сгенерированный QR-код для их прямой загрузки с дисплея.
* `clock_screen` (Tab 2) — Полноэкранные системные часы-заставка. Используются как базовый дневной экран энергосбережения хоста.
* `news_screen` (Tab 3) — Монитор текстовых новостных лент. Поддерживает вертикальный скроллинг и навигационный фокус с помощью курсора пульта.
* `weather_screen` (Tab 4) — Метеорологический комплекс. Отрисовывает графики изменения температурных полей, поддерживает переключение прогноза на 3 дня вперед и выбор индекса графика.
* `settings_screen` (Tab 5) — Двухуровневая интерактивная OSD-матрица конфигурации. Разделена на главную левую панель (переключение флагов будильников и света) и правую панель опций подменю.

## 2. СИСТЕМНЫЕ СЛУЖБЫ И УПРАВЛЕНИЕ РЕСУРСАМИ
* `sleep_daemon.py` — Менеджер энергосбережения и заставок. На основе таймстампа бездействия (`inactivity_sec`) и времени суток (`is_daytime`) рассчитывает ступени диммирования яркости экрана (от 1.0 до 0.05) и громкости. Генерирует три пресета световых будильников (полицейский флеш, стробоскоп с фазовыми паузами, «дышащий» зелёный градиент) с поддержкой 30-секундного плавного рассвета (Fade-in).
* `vlc_engine.py` — Сетевой аудио-драйвер. Управляет медиапотоками через HTTP API локального сервера `cvlc` (Порт `8080`, Пароль `SovIntel`). Предоставляет встроенный массив транслируемых станций и функцию контроля preview-режима станций по 10-секундному таймауту.
* `remote_dispatcher.py` — Изолированный обработчик ввода. Принимает USEREVENT-прерывания Bluetooth-пульта (`evdev`, код ОК — `353`). Обрабатывает навигационные стейты, включает режим «магнита» (Edit Mode) для настройки времени будильника стрелками ВВЕРХ/ВНИЗ и активирует 3-секундный тест световых пресетов.

## 3. ВНЕШНИЕ СВЯЗИ И СБОР ДАННЫХ (DATA CORE)
* `weather.py` — Автономный скрипт сбора метеоданных. Формирует 3-дневную телеметрическую матрицу и кэширует её в файл `weather.txt`.
* `news_grabber.py` — Парсер новостных лент. Собирает актуальные сводки в кэш `news.txt` с фильтрацией через белые/черные списки фраз.
* `config.json` — Статический физический слепок конфигурации. Хранит состояние будильников, пресеты света, громкость и индексы выбранных системных тем.
* `.deep_sleep` / `.marquee_width` — Системные флаги оперативного состояния. Управляют гашением подсветки матрицы и расчётом лимитов сдвига бегущей строки новостей.
