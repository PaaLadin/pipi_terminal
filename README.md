# 📟 SovIntel OS — Персональный Терминал PiPi-Boy v1.0

Добро пожаловать в репозиторий **SovIntel OS**! Это программная оболочка, разработанная специально для миникомпьютеров **Raspberry Pi** и небольших дисплеев (в идеале — под матрицу **em713 с разрешением 1024x600**). 

Проект превращает плату Raspberry Pi в полноценный автономный прикроватный терминал, стилизованный под ретро-интерфейсы, который управляется с обычного Bluetooth-пульта.

## 🌟 Что умеет этот терминал?

* **Полноценный медиацентр (Радио)**: Умеет крутить твои любимые интернет-радиостанции через скрытый фоновый плеер. Есть удобный режим предпрослушивания — переключаешь каналы, слушаешь 10 секунд, и если не нажал "ОК", радио возвращается на прошлую станцию.
* **Умный светозвуковой будильник**: Тебя больше не будут бесить резкие утренние звонки. Первые 30 секунд будильник плавно разгоняет звук от 5% до 100% и запускает один из трёх визуальных пресетов заливки экрана (полицейские огни, стробоскоп с паузами или мягкое зелёное дыхание). Будильник работает 10 минут, но гасится мгновенно нажатием **вообще любой кнопки** на пульте.
* **Метеостанция и Графики**: Терминал сам раз в полчаса забирает погоду, парсит её и строит наглядные графики температурных изменений, а также показывает подробный прогноз на 3 дня вперёд.
* **Следи за халявой (Халявные игры + QR-коды)**: Система мониторит актуальные раздачи игр со 100% скидкой. Если игра раздаётся бесплатно — она выводится на главный экран, а терминал генерирует QR-код. Тебе достаточно просто поднести телефон к экрану PiPi-Boy, отсканировать код и забрать игру!
* **Ленты новостей**: На отдельной вкладке всегда крутится бегущая строка и текстовый монитор свежих новостей, отфильтрованных по твоим личным чёрным и белым спискам ключевых слов.
* **Умное энергосбережение**: Ночью терминал понимает время суток и автоматически гасит экран до комфортных 5% яркости, переходя в режим глубокого сна. Первое нажатие на пульт ночью мягко подсветит экран, а если нажать дважды за 5 секунд — система проснётся на полную мощность.

## 🛠️ Как это устроено внутри?
Проект написан на **Python 3** с использованием библиотеки **Pygame** для отрисовки графики напрямую в Framebuffer (без тяжёлых оконных оболочек Linux). За звук отвечает движок **VLC**, управляемый через локальные HTTP-запросы. Ввод перехватывается на уровне ядра Linux через подсистему **evdev**, что обеспечивает моментальный отклик физических кнопок пульта.

## 🚀 Быстрый запуск
Для развёртывания системы на чистой ОС Raspberry Pi OS достаточно запустить наш автоматический скрипт-инсталлятор:
1. `chmod +x install_pipi.sh`
2. `./install_pipi.sh`
